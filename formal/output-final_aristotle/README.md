# Lean proof of correctness of floating point square root

The top level theorem `sqrtCorrect` found in `Proj/Proof.lean` says the following:

For a trace satisfying `ValidTrace`, at any cycle `t` at which the unit signals completion of a non-special operation, the result is the correctly rounded square root of the operand, in each of the five rounding modes.

`ValidTrace` is a conjunction of properties found in `Proj/Properties.lean` which are SystemVerilog Assertions translated into Lean. 

A square root operation is non-special if the operand is not 0, infinity, Nan, or negative. Special operations are handled directly as SVA (see `SpecialCases` in `../top/formal_fpnew_top.sv`).
